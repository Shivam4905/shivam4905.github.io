## 📊 Understanding the Features

The application uses specific techniques to process solar data. These features ensure you receive reliable results:

*   Geometric Filtering: This method removes noise from raw sensor data. It makes the signal clearer for the prediction engine.
*   Extreme Learning Machine: This model learns from past solar patterns. It predicts future output values based on current weather input.
*   Accuracy-Frugality Trade-off: This setting allows you to choose between maximum precision and faster processing speeds. Use high precision for detailed reports and faster speed for quick daily checks.
*   Feature Selection: The software automatically identifies which weather variables matter most for your specific location.
